# Kidsland

Платформа, где дети учатся программированию в играх, родители видят прогресс, а наставники проводят уроки.
Сейчас готов **Этап 1: игровой портал для детей**.

## Что внутри

```
packages/
  shared/   игровой движок, типы и 10 уровней (общие для клиента и сервера)
  server/   Node.js + Express + TypeScript, JWT, PostgreSQL
  client/   React + TypeScript + Vite, Google Blockly, Canvas
```

- **Игра.** Ребёнок собирает программу из блоков Blockly («Шаг вперёд», «Повернуть», «Собрать монету», «Повторить N раз», «Повторять, пока не у цели», «Если…»), а герой выполняет её на 2D-сетке. Выполняемый блок подсвечивается.
- **Три мира:** космос, океан, роботы. 6 бесплатных уровней и 4 премиум (циклы и условия). Уровни открываются по порядку.
- **Звёзды и награды.** Чем меньше блоков, тем больше звёзд. XP и монеты начисляются только за улучшение результата.
- **Честный подсчёт.** Сервер заново выполняет присланную программу тем же движком, так что звёзды и XP нельзя подделать с клиента.

## Быстрый старт

Нужны Node.js 20+ и Docker (или свой PostgreSQL 13+).

```bash
docker compose up -d                       # PostgreSQL на localhost:5432
npm install
cp packages/server/.env.example packages/server/.env
npm run dev:server                         # API на http://localhost:4000, таблицы и уровни создаются сами
npm run dev:client                         # сайт на http://localhost:5173
```

## Тесты

```bash
npm test                                   # движок и уровни
TEST_DATABASE_URL=postgres://kidsland:kidsland@localhost:5432/kidsland npm test -w @kidsland/server   # API с базой
```

## API

| Метод | Путь | Что делает |
|---|---|---|
| POST | `/api/auth/register` | регистрация родителя `{ email, password }` → `{ token, user }` |
| POST | `/api/auth/login` | вход → `{ token, user }` |
| GET | `/api/auth/me` | текущий пользователь |
| GET | `/api/levels` | публичный список уровней (без решений и конфигов) |
| GET | `/api/children` | профили детей с XP, монетами и пройденными уровнями |
| POST | `/api/children` | новый профиль `{ nickname, avatarUrl? }` |
| GET | `/api/children/:id/levels` | карта уровней ребёнка: звёзды, открыт ли, премиум |
| GET | `/api/children/:id/levels/:slug` | конфиг уровня и сохранённая программа |
| POST | `/api/children/:id/attempts` | отправить программу `{ levelSlug, program }` → звёзды, XP, монеты |

Все пути, кроме регистрации, входа и `/api/levels`, требуют заголовок `Authorization: Bearer <token>`.

## Модель данных

`users` (родитель / репетитор / админ, флаг `is_premium`), `child_profiles` (ник, аватар, монеты, XP),
`levels` (тема, `config_json`, `is_premium`, порядок), `game_progress` (лучшие звёзды, очки, попытки, последняя программа, дата прохождения).
Список пройденных уровней (`completedLevels`) вычисляется из `game_progress`.
