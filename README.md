# Kidsland

Платформа, где дети учатся программированию в играх, родители видят прогресс, а наставники проводят уроки.
Готовы все три контура MVP:

1. **Игровой портал для детей**: блоки Blockly, 2D-поле, 10 уровней в трёх мирах.
2. **Кабинет родителя** (`/parent`): прогресс по темам (последовательности, циклы, условия), звёзды по уровням и приглашение на бесплатный урок, когда базовые уровни пройдены.
3. **Маркетплейс наставников** (`/tutors`): фильтры по предмету, возрасту и языку, профиль с видео-знакомством (ссылка YouTube или загруженный файл), календарь свободного времени, бронирование (первый урок семьи бесплатный) и кабинет наставника (`/tutor`).
4. **Разделы** (`/sections`): программирование, наука и опыты, шахматы, музыка, рисование, досуг (рукоделие, кулинария, шитьё, фокусы), иностранные языки, животные, духовное развитие. У каждого раздела есть темы (например, 10 инструментов в музыке или 11 языков), курсы и наставники; темы и разделы описаны в `packages/shared/src/sections.ts`.
5. **Курсы для самостоятельного обучения** (`/courses`): в программировании 24 курса по 8 направлениям и 3 уровням (всего 70 уроков), в музыке 10 курсов по 7 уроков (9 инструментов и вокал, всего 70 уроков), в остальных разделах вводные курсы по 3 урока.
6. **Побудь админом** (`/be-admin`): любой вошедший пользователь пишет пост, он попадает на проверку в панель администратора (вкладка «Посты на проверку») и публикуется только после одобрения. Посты проходят тот же фильтр безопасности, что и чаты.
7. **Языки интерфейса:** русский, английский, греческий и иврит (иврит справа налево). Словари: `client/src/i18n.en.ts`, `i18n.el.ts`, `i18n.he.ts`, ключи на русском; содержимое уроков пока только на русском. Урок открывается вкладкой «Теория» и засчитывается кнопкой «Я прочитал(а) урок»; вкладки «Задания» и «Викторина» необязательные. Ответы проверяет сервер, за первый зачёт задания или викторины (от 60%) ребёнок получает XP и монеты.
8. **Комната урока** (`/lessons/:id`): видео Jitsi, общая доска для рисования и чат ученика с учителем. Демо-урок с имитацией учителя: `/lessons/demo`.
9. **Служба поддержки** (`/support`) с чатом и панель администратора (`/admin`): ответы на обращения и журнал заблокированных сообщений.
10. **Отмена урока с причиной:** родитель или наставник выбирает причину и может написать сообщение, вторая сторона видит его в карточке урока.
11. **Защита детей:** в чате урока и в анкете наставника блокируются телефоны, почта, адреса, ссылки на мессенджеры и просьбы прислать фото. Каждая попытка попадает в журнал администратора.

На главной странице есть ролик «Робот Кидди»: анимированный рассказ о сайте, который робот озвучивает смешным высоким голосом с «бип-буп» между фразами (синтез речи браузера и WebAudio). Внизу главной контакты: их меняют в `packages/client/src/contacts.ts`.

В шапке есть переключатели: язык интерфейса RU / EN (`i18n.tsx`, словарь `i18n.en.ts`; тексты уроков пока на русском), светлая и тёмная тема и панель «Особые возможности» (крупный текст, высокий контраст, шрифт для дислексии, интервалы, без анимаций, выделение ссылок, чтение вслух). Настройки хранятся в браузере.

Для разработки сервер сам создаёт 6 демо-наставников со свободным временем на 2 недели вперёд и администратора `admin@kidsland.local` / `admin12345` (только вне `NODE_ENV=production`). В продакшене администраторов задаёт `ADMIN_EMAILS` (через запятую): эти пользователи получают роль `admin` при входе.

Загруженные видео наставников хранятся в `packages/server/uploads` (`UPLOADS_DIR`, лимит `MAX_VIDEO_MB`, по умолчанию 100).

## Что внутри

```
packages/
  shared/   игровой движок, 10 уровней, курсы, разделы и фильтр безопасности (общие для клиента и сервера)
  server/   Node.js + Express + TypeScript, JWT, PostgreSQL
  client/   React + TypeScript + Vite, Google Blockly, Canvas
```

- **Игра.** Ребёнок собирает программу из блоков Blockly («Шаг вперёд», «Повернуть», «Собрать монету», «Повторить N раз», «Повторять, пока не у цели», «Если…»), а герой выполняет её на 2D-сетке. Выполняемый блок подсвечивается.
- **Три мира:** космос, океан, роботы. 6 бесплатных уровней и 4 премиум (циклы и условия). Уровни открываются по порядку.
- **Звёзды и награды.** Чем меньше блоков, тем больше звёзд. XP и монеты начисляются только за улучшение результата.
- **Честный подсчёт.** Сервер заново выполняет присланную программу тем же движком, так что звёзды и XP нельзя подделать с клиента.

## Быстрый старт

Нужны Node.js 20+ и Docker (или свой PostgreSQL 13+).

```bash
docker compose up -d                       # PostgreSQL на localhost:5433
npm install
cp packages/server/.env.example packages/server/.env
npm run dev                                # API на :4000 и сайт на http://localhost:5173 одной командой
```

На Windows можно просто дважды кликнуть `start.cmd`: он запустит базу, поставит зависимости, запустит сервер и сайт и откроет браузер.

По отдельности: `npm run dev:server` и `npm run dev:client`.

## Тесты

```bash
npm test                                   # движок и уровни
TEST_DATABASE_URL=postgres://kidsland:kidsland@localhost:5433/kidsland npm test -w @kidsland/server   # API с базой
```

## API

| Метод | Путь | Что делает |
|---|---|---|
| POST | `/api/auth/register` | регистрация родителя `{ email, password }` → `{ token, user }` |
| POST | `/api/auth/login` | вход → `{ token, user }` |
| GET | `/api/auth/me` | текущий пользователь |
| GET | `/api/levels` | публичный список уровней (без решений и конфигов) |
| GET | `/api/children` | профили детей с XP, монетами и пройденными уровнями |
| POST | `/api/children` | новый профиль `{ nickname, avatarUrl? }` |
| GET | `/api/children/:id/levels` | карта уровней ребёнка: звёзды, открыт ли, премиум |
| GET | `/api/children/:id/levels/:slug` | конфиг уровня и сохранённая программа |
| POST | `/api/children/:id/attempts` | отправить программу `{ levelSlug, program }` → звёзды, XP, монеты |
| GET | `/api/children/:id/report` | отчёт для кабинета родителя |
| GET | `/api/tutors?subject=&language=&age=&sort=` | каталог наставников (публичный) |
| GET | `/api/tutors/:id` | профиль наставника и свободные слоты на 30 дней |
| POST | `/api/bookings` | записаться `{ slotId, childId }`; первый урок семьи бесплатный |
| GET | `/api/bookings` | уроки родителя или наставника |
| GET | `/api/bookings/:id` | урок и ссылка на видеокомнату |
| POST | `/api/bookings/:id/cancel` | отменить будущий урок |
| GET/PUT | `/api/tutor/profile` | профиль наставника (роль `tutor`) |
| GET/POST | `/api/tutor/slots` | расписание наставника, добавить слоты `{ startsAt: [ISO] }` |
| DELETE | `/api/tutor/slots/:id` | удалить свободный слот |
| POST/DELETE | `/api/tutor/video` | загрузить видео-знакомство (тело запроса: файл mp4/webm/mov) или удалить |
| GET | `/api/children/:id/courses` | прогресс ребёнка по урокам курсов |
| POST | `/api/children/:id/lessons/:lessonId/submit` | ответы `{ answers }` → баллы, зачёт, награды |
| GET | `/api/bookings/:id/room?after=&board=` | новые сообщения чата и доска урока |
| POST | `/api/bookings/:id/messages` | сообщение в чат урока (с фильтром безопасности) |
| POST | `/api/bookings/:id/board`, `/board/clear` | добавить линию на доску, очистить доску |
| GET | `/api/support`, POST `/api/support/messages` | чат пользователя с поддержкой |
| GET/POST | `/api/support/admin/...` | обращения, ответы, статус, журнал безопасности (роль `admin`) |

Регистрация принимает `role: "parent" | "tutor"`. Все пути, кроме регистрации, входа, `/api/levels` и `/api/tutors`, требуют заголовок `Authorization: Bearer <token>`.

## Онлайн-уроки

Ссылка на урок создаётся на Jitsi Meet (`JITSI_DOMAIN`, по умолчанию `meet.jit.si`). Публичный `meet.jit.si` во встроенном окне ограничивает звонок 5 минутами, поэтому на странице урока есть кнопка «открыть в новой вкладке». Для продакшена нужен свой сервер Jitsi или 8x8 JaaS: поменяйте `JITSI_DOMAIN`.

## Модель данных

`users` (родитель / репетитор / админ, флаг `is_premium`), `child_profiles` (ник, аватар, монеты, XP),
`levels` (тема, `config_json`, `is_premium`, порядок), `game_progress` (лучшие звёзды, очки, попытки, последняя программа, дата прохождения),
`tutor_profiles` (предметы, языки, возраст, цена, рейтинг, публикация), `tutor_slots` (свободное время), `bookings` (урок, статус, пробный или платный, ссылка на видеокомнату).
`course_progress` (лучший результат по уроку курса), `support_threads` / `support_messages` (поддержка), `lesson_messages` / `lesson_boards` (чат и доска урока), `safety_flags` (заблокированные сообщения).
Список пройденных уровней (`completedLevels`) вычисляется из `game_progress`. Содержимое курсов лежит в `packages/shared/src/courses`.
